# Half Batch website (halfbatch.studio)

The studio site, published with GitHub Pages: the home page, the kipple page with its privacy policy and support page, a website privacy notice and a contact / Impressum page.

## Privacy

The site shows no personal details by default:

- `commercial: false` in `_config.yml`: no name or address anywhere. The contact page says it's a private, non-commercial project and gives only the contact email.
- `commercial: true`: shows a full Impressum with your name and a postal address. Use a business or virtual-office address, never your home. Switch it on before charging for anything.
- Fonts are self-hosted (SIL Open Font License, see `assets/fonts/`), so visitors' data isn't sent to Google Fonts. No cookies, no analytics.
